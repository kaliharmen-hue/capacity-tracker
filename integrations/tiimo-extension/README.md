# Tiimo diagnostic (prototype)
Manual, read-only, local-only Chrome Manifest V3 extension. No network requests, storage, credentials, or background monitoring. Uses activeTab permission only after user opens the extension. Install unpacked from this directory using chrome://extensions and Developer mode. Open Tiimo, click the extension, then Read visible planner. Compare the displayed date range, tasks and times against Tiimo. Do not publish or commit captured output: it may contain private or work information. This diagnostic is not a production parser; completion status, stable identifiers and calendar provenance are not yet established. Next: test date navigation, list visibility and freshness; then design a narrowly scoped authenticated sync endpoint and separate planner storage. Never treat missing visible tasks as deletions. Keep existing health records and free-tier safeguards unchanged.
